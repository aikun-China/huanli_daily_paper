# 幻璃次元日报 - 开发文档

## 架构概览

```
┌─────────────────────────────────────────┐
│           真寻Bot / NoneBot2            │
├─────────────────────────────────────────┤
│  命令层: 日报/今日角色/投票/设置...      │
├─────────────────────────────────────────┤
│  数据管理层                              │
│  ├── CharacterPicker (角色抽取)         │
│  ├── EventPicker (事件抽取)             │
│  ├── HolidayChecker (节日查询)          │
│  ├── CountdownCalculator (倒计时)       │
│  ├── TriviaPicker (冷知识)              │
│  └── VoteManager (投票管理)             │
├─────────────────────────────────────────┤
│  渲染层: DailyRenderer (BuildImage)     │
├─────────────────────────────────────────┤
│  数据源                                  │
│  ├── 本地JSON (角色/事件/节日/投票)      │
│  ├── 网络抓取 (B站/微博热搜)             │
│  └── DeepSeek API (AI分析)              │
└─────────────────────────────────────────┘
```

## 添加新IP

1. 在 `data/ip_index.json` 中添加IP信息
2. 创建 `data/characters/{ip}/` 文件夹
3. 创建 `assets/characters/{ip}/` 文件夹
4. 添加角色JSON文件
5. 准备角色立绘图片

## 添加新主题

1. 在 `assets/themes/` 下创建新文件夹
2. 放入 `bg.png`（背景底图，建议900x1400）
3. 放入 `font.ttf`（主题字体，可选）
4. 群配置中设置 `theme: "新主题名"`

## 定时任务

| 任务ID | 时间 | 函数 | 说明 |
|--------|------|------|------|
| daily_paper_update_events | 7:30 | scheduled_update_events | 抓取热事 |
| daily_paper_morning | 8:00 | scheduled_daily | 发送日报 |
